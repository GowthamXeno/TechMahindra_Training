# AEM Assignments

## Overview
This folder contains all the assignments related to **Adobe Experience Manager (AEM)** that I have worked on. Through these tasks, I have explored various AEM concepts, implemented components, and gained hands-on experience in building and structuring AEM-based web pages.

## Assignments Covered
- **Newsroom Portfolio Website**: Implemented a complete newsroom website with header, footer, news pages, journalist profiles, and contact details.
- **OOTB Component Usage**: Learned how to use and customize Out-Of-The-Box (OOTB) components in AEM.
- **Custom Components**: Developed custom components such as the **NewsRoom Component** to dynamically fetch and display news articles.
- **HTL & Sling Models**: Gained experience in **HTL (Sightly)** and **Sling Models** for rendering dynamic content.
- **Page & Template Authoring**: Explored how to create pages using content templates and structure them properly within the AEM repository.
- **Content Fragment & DAM Usage**: Worked with **AEM Content Fragments** and **Digital Asset Manager (DAM)** to manage media assets efficiently.

## Learnings & Exploration
During these assignments, I explored:
- **AEM Site Structure & Content Hierarchy**
- **OOTB Templates vs. Custom Templates**
- **HTL Best Practices & Java Sling Models**
- **Content Fragment Models & Reusability**
- **AEM Workflows & Publishing Process**
